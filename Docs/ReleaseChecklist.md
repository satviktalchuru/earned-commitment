# Earned Commitment Release Checklist

## Prepared locally

- Privacy policy hosted over HTTPS.
- Support URL hosted over HTTPS.
- Bundle identifier set to `com.satviktalchuru.earnedcommitment`.
- App Store listing copy prepared in `AppStoreConnectMetadata/en-US`.
- Review notes, privacy answers, age-rating draft, and export-compliance draft prepared.
- Launch background and orientation declarations added.

## Requires Apple Developer access

- Register the bundle ID under the Apple Developer Team.
- Set `DEVELOPMENT_TEAM` in Xcode and enable automatic signing.
- Install an iOS Simulator runtime or connect a physical iPhone.
- Capture and upload final screenshots.
- Create the App Store Connect app record.
- Set category to Productivity.
- Enter the privacy URL and support URL.
- Complete the age-rating questionnaire.
- Confirm App Privacy answers.
- Complete export compliance.
- Upload a signed archive through Xcode Organizer.
- Run TestFlight internal testing before review.
